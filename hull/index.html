凸包と輪郭の字間(試し)

盲検ではありません。各項目の上の行は、隣り合う 2 字の「境界の図形」が接するところまで寄せてから、全部の組を同じだけ広げたものです。下の行「元」は字間を足さない元の組みです(参考)。
境界の図形は、凸包(字を輪ゴムで囲んだ形)と、字の輪郭を距離 r だけ太らせた形を合わせたものです。「和」は凸包に太らせた輪郭を足した形(r = 0 で凸包だけ)、「積」は凸包のうち輪郭から r 以内の部分(r = 0 で字そのもの)です。帯は使いません。
図形・全体を広げる量・字種の足しは、上の帯で節ごとに決めます。各項目の「この項目だけ足す」は、その項目にだけ上乗せします(初期 0)。広げる量 0 で図形どうしがちょうど接します。初期値は、記事の全部の組の真ん中の組が元の送りのままになる量です。約物(palt が効くもの)・空白の組は凸包を使わず、つまみも効きません。
見やすい量に合わせ、許容できるかとひとことを書いて「記録」を押してください。最後に「共有用のテキストを出す」でコピーして送ってください。
